# Plan — Issue #2: Add deleteBuild method to API service

> Generated by Tsukinome. The technical blueprint for the work, approved before any code.

## Summary

Add a single public deleteBuild(buildId) method to the existing ApiService that returns this.http.delete<...>(`${API_BASE}/api/builds/${buildId}`), mirroring the existing getBuild/query/createBuild one-liner pattern. Introduce a small response interface for the success acknowledgement. Cover it with a Vitest spec using the existing hand-rolled HttpClient double, extended with a delete mock.

## Approach

The service methods are all thin one-liners that delegate directly to HttpClient and return the observable without subscribing. deleteBuild follows the same idiom exactly: interpolate buildId into the URL path using the same template-literal approach as getBuild (`${API_BASE}/api/builds/${buildId}`), no added encoding, and return this.http.delete(...) directly. A DeleteBuildResponse interface is added alongside the other response interfaces to type the success acknowledgement, matching how CreateBuildResponse/QueryResponse are declared. Tests reuse the existing makeHttp() double; since it currently only stubs post/get, add a delete: vi.fn().mockReturnValue(of({})) so the delete call can be asserted and its return value verified. No routing, DI provider, or backend changes are needed — provideHttpClient already exposes DELETE support.

## Affected Files

- `frontend/src/app/services/api.service.ts` **(modify)** — Add public deleteBuild(buildId: string) method and a DeleteBuildResponse interface following existing CRUD patterns.
- `frontend/src/app/services/api.service.spec.ts` **(modify)** — Extend the HttpClient double with a delete mock and add tests asserting the DELETE URL, observable pass-through, and acknowledgement emission.

## Contracts

- interface DeleteBuildResponse { ok: boolean } (success acknowledgement shape returned by DELETE /api/builds/:id)
- ApiService.deleteBuild(buildId: string): Observable<DeleteBuildResponse> — returns this.http.delete<DeleteBuildResponse>(`${API_BASE}/api/builds/${buildId}`)

_None._
